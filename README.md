Disney Trivia — Family Game Night Edition
A lightweight, fast, browser‑based trivia game built with HTML, CSS, and JavaScript.
Designed for family game nights, Disney fans, and anyone who loves a quick round of trivia magic.
The app supports:
Flashcard mode
Multiple‑choice mode
Category filtering
Movie filtering
Shuffle / Next / Previous navigation
Custom choices per question
Expandable trivia packs
No frameworks. No build tools. Just clean, simple, portable code.
✨ Features
🔹 Two Game Modes
Flash Card — Tap to reveal the answer
Multiple Choice — Auto‑generated or custom choices
🔹 Smart Filtering
Filter questions by:
Category (Characters, Geography, etc.)
Movie (Frozen, Mulan, Bambi, etc.)
Or show All questions
Both filters work together.
